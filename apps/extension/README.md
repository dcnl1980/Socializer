# Socializer Capture Extension

Capture-only Chrome MV3 extension. It scrapes the open LinkedIn profile and POSTs it to Socializer. It does **not** send invites or messages.

## Load unpacked

1. Open `chrome://extensions`
2. Enable Developer mode
3. Load unpacked → select `apps/extension`
4. Set API origin (`http://localhost:3000`) and a List ID from the Leads page
5. Open a LinkedIn profile → click **Save current profile**
